# Tracking Device Detector — Legal & Support Pages

## Before publishing
1. Replace `YOUR_SUPPORT_EMAIL_HERE` with the new support email.
2. Replace `[LEGAL DEVELOPER NAME]` with the legal owner/developer name after acquisition.
3. Replace `[DATE]` in both policies with the publication date.
4. Review every statement against the shipped app, SDKs, App Store privacy disclosures, subscription setup, and actual data practices. This is a starter template, not legal advice.
5. Remove or update references to third-party providers not used in the acquired build.

## Publish with GitHub Pages (no command line)
1. Sign in to GitHub and create a repository, e.g. `tracking-device-detector-legal`. Public is simplest on GitHub Free.
2. Download and unzip this package.
3. Open the new repository, choose **Add file → Upload files**, and upload `index.html` (and this README if desired) from the unzipped folder. Commit the upload to the `main` branch.
4. In the repository, go to **Settings → Pages**.
5. Under **Build and deployment → Source**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for deployment. In **Settings → Pages**, click **Visit site**. The URL will look like `https://YOUR-GITHUB-USERNAME.github.io/tracking-device-detector-legal/`.
8. Open the URL and test the Privacy Policy, Terms of Use, Support links and email placeholder.
9. Add that URL to the app's privacy-policy/support settings and App Store Connect fields as appropriate. If Apple asks for a Terms of Use URL, link to this page (or a separate terms page if you later split files).

## Updating later
Edit `index.html` in GitHub (click file → pencil → commit changes). GitHub Pages redeploys after the commit, sometimes taking several minutes.

## Important
GitHub Pages content is public. Do not put private information, credentials, or internal acquisition documents in this repository.
